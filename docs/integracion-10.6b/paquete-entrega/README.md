# Paquete de revisión institucional — Genares 10.6B

Este paquete contiene copias de trabajo de los diagramas y documentos breves de revisión. Los diagramas `.mmd` pueden abrirse en Mermaid Live Editor o en una extensión compatible.

- `01-der-actual.mmd`: esquema físico de las migraciones del repositorio.
- `02-der-actual-mas-propuesta.mmd`: añade entidades futuras marcadas `PROP_`.
- `03-der-integracion-conceptual.mmd`: sistemas externos como dominios conceptuales; no representa sus tablas físicas.
- `04-flujo-integracion.mmd`: flujo, no DER.
- `05-resumen.md` y `06-matriz-integracion.md`: contexto y decisiones pendientes.

PostgreSQL 9D estaba apagado durante la auditoría. Los hallazgos del esquema son estáticos; este paquete no afirma que se haya verificado una base viva o renderizado los diagramas.
