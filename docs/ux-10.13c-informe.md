# 10.13C — Claridad académica

Fecha: 24 de octubre de 2026

## Alcance

Se implementó la fase 10.13C sobre el frontend `prototipo-titulacion`, siguiendo la auditoría 10.13A y la consistencia visual de 10.13B. No se cambiaron fórmulas, notas, rúbricas persistidas, actas, contratos API ni migraciones.

## Cambios realizados

### Estados de evaluación

- Las evaluaciones del prototipo y de la consulta API presentan estados distinguibles:
  - «Abierta · pendiente» cuando todavía no existe un borrador.
  - «Abierta · borrador» cuando hay trabajo guardado que puede continuar.
  - «Cerrada» o «Cerrada · solo lectura» cuando el servidor o el prototipo bloquean la edición.
  - «Incompleta»/«Cerrada incompleta» cuando faltan etapas o evaluadores.
- La pantalla API mantiene separado el permiso de escritura del estado del registro. Una evaluación cerrada se presenta como solo lectura aunque el contexto del miembro tenga capacidad operativa.
- Se reemplazó «Finalizada» en las pantallas de evaluación por «Cerrada» para no confundir cierre de captura con oficialidad del resultado.

### Ámbito de cada etapa

- Las etiquetas técnicas se muestran como:
  - «Compartida por trabajo».
  - «Individual por estudiante».
- La evaluación escrita explica que su calificación se reutiliza para cada estudiante del trabajo.
- La evaluación oral identifica que cada formulario, borrador y cierre pertenece únicamente al estudiante seleccionado, incluso en la vista comparativa.
- La consulta API mantiene la identificación técnica del ámbito en los atributos accesibles, sin sustituir la explicación visible.

### UX-04 — Escala y máximos de rúbrica

- El detalle de rúbrica identifica la «suma de máximos por etapa» como una suma estructural y aclara que no es la nota final.
- Cada etapa identifica su máximo como puntos propios de esa etapa.
- Los resultados muestran la calificación consultiva sobre 10.00. No se alteró ninguna suma, promedio ni conversión existente.

### UX-07 — Umbral y oficialidad

- Las pantallas de resultado y documentos identifican 7.00/10.00 como umbral de aprobación provisional.
- «APROBADO» y «REPROBADO» se presentan como rótulos provisionales/no oficiales.
- Se unificaron las etiquetas:
  - «Resultado consultivo» para consolidaciones informativas.
  - «Documento preliminar» para vistas previas sin número.
  - «Acta archivada» para documentos numerados recuperados del archivo.
- La vista de rúbrica impresa se identifica como «Documento preliminar · evaluación cerrada»; no se presenta como acta institucional.
